## 真机及验收

当前环境只提供 Linux 浏览器，没有 iPhone 或 Android 真机连接。真机 iOS Safari 和 Android Chrome 的系统旋转、地址栏与安全区变化、多指及长按系统菜单、首次手势音频和移动性能待验收。十关结果为辅助落地回归。完整真人飞行以及长时间内存、热降频和耗电未测试。

## Windows 交接复测

本机 Chrome 通过 Playwright 模拟四组触屏视口。390×844 注入顶部 47px、底部 34px 安全区，844×390 注入左右各 47px、底部 21px 安全区。

| 视口 | 结果 |
|---|---|
| 320×568、390×844 | 控件热区、SVG 图标与标签、安全区、统计弹层隔离、双指转向加推力、暂停和设置交互均通过 |
| 568×320、844×390 | 同一组检查均通过 |

五个可见飞行控件的热区均至少 44×44 CSS px，彼此无交叉。使用 CDP 验证真实浏览器双指事件及取消，使用合成 Pointer Events 补测单指释放和捕获丢失。暂停期间开关设置后仍保持暂停，飞船位置与燃料冻结。四组页面 JS 异常为 0。

目查四组航线图和 D5 HUD 截图。568×320 的 D5 画面中，低燃料提示与背景「地球」标签出现局部叠放，留待真机复核。Windows 复测未重跑 Linux 双引擎完整矩阵或 60 次辅助着陆。预览版本与交接证据见 [Windows 交接记录](sprint-09/windows-handoff.md)。
