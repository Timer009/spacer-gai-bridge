# Sprint 09 发布归档

发布版本为 Spacer `fbc8e0f2f6d37beabb5a4545c46e54a54e1c7d42`。Spacer 与 Bridge 使用 `sprint-09` 归档标签。发布游戏文件 SHA-1 为 `e39de1ae46039f6348f95bf569efd9aaf44a22d6`。

用户确认 iOS Safari、iOS Chrome、iOS Edge、Android Chrome 和 Android Edge 的真机横屏验收通过。iOS 和 Android 夸克 P1-4 作为已知兼容缺陷暂缓，原生横屏原因仍待设备诊断。兼容横屏入口保留，P1-4 不再阻塞发布或后续开发。 [跨浏览器收尾记录](browser-closeout.md)

以最终发布提交重跑 Windows Chrome、Playwright WebKit、Firefox 和 Edge 回归。各通过十关启动、推力、预测、碰撞、重生、辅助三星着陆及进度存档，合计 40 次辅助着陆。验证动态横竖屏、多指、暂停、退出兼容、安全区及诊断记录。通过用例无页面 JS 异常。四套桌面环境为自动化模拟，手机结果来自用户反馈。
